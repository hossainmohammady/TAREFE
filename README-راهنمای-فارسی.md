# اپلیکیشن اندروید محاسبه کرایه بار

این پروژه بر اساس آخرین فایل ارسالی شما آماده شده است. رابط کاربری و محاسبات فعلی حفظ شده و با Capacitor در قالب اپ اندروید اجرا می‌شود.

## چه چیزهایی حفظ شده‌اند؟
- فرم محاسبه و انتخاب شهر
- تعرفه‌ها و مدیریت شهرها (افزودن، ویرایش، حذف و جستجو)
- محاسبه کرایه پایه، کرایه کل، بیمه و کمیسیون
- تنظیمات بیمه و درصد کمیسیون پیش‌فرض
- حالت روشن و تاریک
- ذخیره شهرها و تنظیمات روی همان گوشی
- پشتیبان‌گیری و بازیابی JSON؛ خروجی در اندروید از طریق پنجره اشتراک‌گذاری گوشی انجام می‌شود
- رابط فارسی و منوی پایین شیشه‌ای

## پیش‌نیازهای ساخت APK در ویندوز
1. Node.js نسخه 22 یا بالاتر
2. Android Studio نسخه سازگار با Capacitor 8 (حداقل Android Studio 2025.2.1)
3. Android SDK از داخل Android Studio؛ حداقل Platform API 24 یا بالاتر
4. اتصال اینترنت هنگام نصب اولیه بسته‌های npm و دریافت اجزای Gradle/SDK

## ساخت اولیه
1. ZIP را استخراج کنید.
2. فایل `راه‌اندازی-اندروید.bat` را اجرا کنید.
3. بار اول، npm بسته‌ها را دریافت می‌کند و پوشه Android ساخته می‌شود.
4. Android Studio باز می‌شود؛ صبر کنید Gradle Sync کامل شود.
5. از منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)** فایل APK را بسازید.
6. پس از پایان، روی **locate** کلیک کنید تا محل APK نمایش داده شود. معمولاً مسیر آن `android/app/build/outputs/apk/debug/app-debug.apk` است.

## ساخت APK در دفعات بعد
پس از تغییر HTML/CSS/JS، فایل `به‌روزرسانی-بعدی.bat` را اجرا کنید، سپس در Android Studio دوباره Build APK(s) را بزنید.

## شناسه و نام برنامه
- نام نمایشی: محاسبه کرایه بار
- شناسه بسته: `ir.freightcalculator.app`

## نکات مهم
- برنامه برای اجرای محاسبات به اینترنت نیاز ندارد؛ اما نصب اولیه وابستگی‌ها و ساخت Android ممکن است اینترنت بخواهد.
- اطلاعات localStorage مرورگر قبلی به‌طور خودکار وارد اپ نمی‌شود. برای انتقال داده‌ها، از نسخه قبلی در مرورگر خروجی JSON بگیرید و در اپ اندروید از گزینه بازیابی استفاده کنید.
- خروجی پشتیبان در اندروید با پنجره اشتراک‌گذاری سیستم ارائه می‌شود تا بتوانید آن را در فایل‌ها ذخیره یا برای خود ارسال کنید.
